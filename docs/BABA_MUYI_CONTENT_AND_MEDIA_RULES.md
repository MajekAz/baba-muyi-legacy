# Baba Muyi Content and Media Rules

## Content Accuracy

Use only established project facts and approved repository content. Do not invent dates, quotations, precise business timelines, locations, captions, family interpretations, or historical claims.

Known archive context:

- Alhaji Tioluwalase "Baba Muyi" Majekodunmi.
- Family roots connected to Iboogun and Abeokuta.
- Later associated with Bariga.
- Entrepreneur in transport.
- Bolekaja and Molue transport history.
- TIOLUWA LASE bus identity.
- Father, community leader and humanitarian legacy.
- Died in 2008.
- Archive documented by Azeez Adeyemi Majekodunmi.

## Public Content Rules

Public pages may render only records that are:

- published
- public
- scoped to the active workspace and legacy profile
- approved where moderation applies

Public pages must not render:

- drafts
- in-review records
- scheduled records before publication
- archived records
- private or family-only records
- rejected records
- raw private storage paths

## Media Rules

Use only:

- approved public Media Library records
- existing project assets with clear provenance
- safe non-photographic fallbacks when no approved image exists

Every meaningful image should have:

- alt text
- caption when available
- attribution or source when available
- no invented dates, names, locations or captions

## Empty States

Empty states should be respectful and visitor-facing. They must not expose developer language, database details, or CMS internals.

If a homepage preview query fails, the public page should render an empty state rather than expose an error boundary. This fallback must not fetch less-restricted content, use privileged credentials in the browser, or substitute private/unpublished records.

## Public Contributions

Milestone 4 Phase 1 does not introduce a new public memory-submission workflow.
